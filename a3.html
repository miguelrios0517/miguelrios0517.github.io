// I want to explore caves so I wired a circuit that increases brightness of LED the darker the environment is

int analogPin = A2; //set analog pin for photocell
int red = 9; //set red LED pin
int green = 10; //set green LED pin
int blue = 11; //set blue LED pin
int val = 0; //intialize val -> stores analogRead(analogPin)
int val_map = 0; //intialize val_map -> stores a map() value from [0,1024] to [0,255]


void setup() {
  Serial.begin(9600); //  setup serial
  pinMode(red, OUTPUT); //setup red LED pin as OUTPUT 
  pinMode(green, OUTPUT); //set green LED pin as OUTPUT
  pinMode(blue, OUTPUT); //set blue LED pin as OUTPUT 
}
  
void loop() {
  val = analogRead(analogPin); // read Vout
  Serial.println(val); //print Vout
  val_map = map(val, 0,1024, 0, 255); // map Vout from [0,1024] to [0,255] so we can pass it to LED pins -> store as val_map
  if (val_map >= 0 && val_map <= 255){ // check to see if val_map is in range of 0 to 255
    analogWrite(red, (int)(255 - val_map)); //set red LED duty cycle to 255 minus val_map (lower illuminance -> brighter LED)
    analogWrite(blue, (int)(255 - val_map)); //set blue LED duty cycle to 255 minus val_map         
    analogWrite(green, (int)(255 - val_map));  //set green LED duty cycle to 255 minus val_map           
  }
  delay(200); // delay 200 miliseconds before starting next loop
}

Question 1: In your voltage divider, can the variable resistor be either R1 or R2 or does it need to be one or the other? Justify your answer with example calculations.


The variable resistor can be R1 or R2, but this will determine the relationship with Vout (direct or inverse). In our current circuit where the variable resistor = R2, there is a direct relationship with Vout. Vout increases the more light is shined on the photocell. However, if the variable resistor was R1, Vout would decrease the more light is shined. This might actually be a more ideal setup for my circuit since I want my LED to shine brighter the darker the environment is.

Resistances

Variable Resitor (photocell) in dark conditions = 10k ohm
Variable Resitor (photocell) in light conditions = 1k ohm

Resistor = 10k ohm

Calculations

If variable resistor was R1:
dark conditions => Vout = 10000/(10000 + 10000) * 5v = 2.5v
light conditions => Vout = 10000/(10000 + 1000) * 5v = 4.55v
... this means more light equals greater vOut!

If variable resistor was R2
dark conditions => Vout = 10000/(10000 + 10000) * 5v = 2.5v
light conditions => Vout = 1000/(10000 + 1000) * 5v = 0.45v
... this means more light equals lower vOut!

Question 3: AnalogWrite and analogRead are respectively 8-bit and 10-bit values. Imagine you had 10-bit PWM and a 16-bit analog-to-digital converter instead. How would this change your map() code? Explain your answer.


In order to map a 16-bit analog-to-digital to 10-bit PWM I would have to map [0,65535] to [0,1024] since the largest 16-bit number is 65,535. This is what the function call would look like:

map(val, 0, 65535, 0, 1024).
